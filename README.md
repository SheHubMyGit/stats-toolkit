A collection of functions to conduct basic mathematical and statistical calculations

mean(values) - Returns the quotient of the sum of all the numbers in a non-empty list divided by the number of components in the list

median(values) -Returns the median of a non-empty list

sqrt(values) - Returns the square root of a number

std_dev(values) - Returns the sample standard deviation of a the numbers in a list of at least 2 numbers

to_number(values) - Returns the float value of an inputted value. If it cannot be converetted, returns None.

is_valid_score(values) - Checks if a number is within the normal grading scale of 0 - 100

To test the functions, clone the repo, create a virtual environment and run" pip install pytest ", and  "python -m pytest -q "
