A collection of functions to conduct basic mathematical and statistical calculations

mean(value) - Returns the quotient of the sum of all the numbers in a non-empty list divided by the number of components in the list

median(values) -Returns the median of a non-empty list

sqrt(values) - Returns the square root of a number

std_dev(values) - Returns the sample standard deviation of a the numbers in a list of more than 2 numbers

to_number(values) - Returns the float value of an inputed value. If it cannot be convereted, returns None.

is_valid_score(values) - Checks is a number is within the normal grading scale of 0 - 100

To test the functions, install, create a test file, input the desired conditions, download pip and pytest using " pip install pytest ", and run the tests using " python -m pytest -q "
